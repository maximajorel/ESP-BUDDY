    Spotify

    Lo que está sonando, en la pantalla MUSICA.

    Conectar tu cuenta

    Cómo preparar la app de Spotify
    1. Entrá a developer.spotify.com/dashboard con tu cuenta de Spotify y creá una app. El nombre que le pongas da igual.
    2. Dentro de esa app, agregá esta dirección como Redirect URI, copiada tal cual y sin espacios: http://127.0.0.1:8888/callback
    3. Copiá el Client ID que muestra la app y pegalo en el campo de arriba.

    Autorizar el equipo

    1. Tocá Autorizar y abrí el enlace que aparece.
    2. Entrá con tu cuenta de Spotify y tocá Aceptar.
    3. El navegador va a intentar volver a la dirección de abajo y va a mostrar un error de conexión. Eso es esperado: esa dirección vive en tu computadora, no en el teléfono.
    4. Sin cerrar esa pestaña, copiá de la barra de direcciones todo lo que está después de code= y antes del próximo &. Ese valor es el código.

    Enlace para dar el permiso (se abre en una pestaña nueva):

    Después de aprobar, la página va a fallar al volver y vas a ver un error de conexión con 127.0.0.1. Es normal. No cierres esa pestaña: copiá el valor de code= desde la barra de direcciones y pegalo abajo.

    La dirección de vuelta configurada en tu app tiene que ser http://127.0.0.1:8888/callback

    Sirve la dirección entera o sólo lo que está después de code=: el equipo saca el código solo.

    Hermes (bridge)

    El bridge es el que sabe qué está haciendo Hermes y el que guarda las credenciales de Google.

    El panel guarda la URL y los dos tokens; la clave de Hermes no pasa por el equipo. El de administración es el que habilita escribir en el bridge: sin él el panel no puede pedirle cosas a Sofía ni cambiar el estado del lado del bridge. Ejemplos: http://192.168.100.64:8787 en tu LAN, o https://bridge.tu-dominio.com con un túnel. Con https:// el equipo valida el certificado solo: no hay que subir nada.

    Preparar Google (una sola vez)

    1. Entrá a Google Cloud y creá un proyecto (o usá uno que ya tengas). Es gratis.
    2. Abrí Google Calendar API y tocá Habilitar.
    3. En Pantalla de consentimiento OAuth elegí Externo, poné un nombre (por ejemplo Sofía) y tu correo. En Permisos agregá https://www.googleapis.com/auth/calendar.readonly. Agregá tu cuenta como usuario de prueba y tocá Publicar app: si queda en Prueba, Google vence el permiso a los 7 días.
    4. En Credenciales → Crear credenciales → ID de cliente de OAuth → tipo de aplicación TVs and Limited Input devices (TV y dispositivos de entrada limitada). Copiá el Client ID y el Client secret.
    5. Pegalos acá abajo y tocá Guardar. Después Conectar con Google, abrí el enlace, escribí el código y aprobá. Volvé a este panel: la lista de calendarios aparece sola.

    El equipo no necesita una URL pública ni el bridge. El permiso es de sólo lectura: el equipo no puede crear, editar ni borrar eventos.
